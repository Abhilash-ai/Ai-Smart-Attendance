# 🎯 # 🎯 AI Smart Attendance System (Face Recognition Based)

An AI-based attendance system using **Face Recognition** to automate attendance marking.  
No manual register, no proxy — just camera + intelligence.

---

## 🚀 Features

- 👤 Face Registration (capture multiple images)
- 🧠 Face Recognition using Deep Learning
- 📸 Real-time camera detection (OpenCV)
- 📝 Automatic attendance marking (CSV)
- 📊 Dashboard using Streamlit
- ⚡ Fast and easy to use

---

## 🛠️ Tech Stack

- Python
- OpenCV
- DeepFace
- TensorFlow / tf-keras
- Pandas
- Streamlit

---

## 📁 Project Structure
Smart Attendence/
│
├── register.py # Register new users
├── recognize.py # Face recognition & attendance
├── dashboard.py # Dashboard (Streamlit)
├── attendance.csv # Attendance data
├── dataset/ # Stored face images
└── test_face.py # Camera testing
 

---

## ▶️ How to Run

1. Register users:   python register.py
   
2. Start recognition: python recognize.py
   
3. Open dashboard: streamlit run dashboard.py


---

## 📊 Output

- Detects faces in real time  
- Marks attendance automatically  
- Stores data in CSV  
- Displays records in dashboard
